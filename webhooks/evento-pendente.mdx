O evento `pending` é disparado quando a transação entra no status `waiting_payment`.

| Propriedade | Valor |
| --- | --- |
| Evento configurado no painel | `pending` |
| `status` no payload | `waiting_payment` |
| Significado | PIX criado e aguardando pagamento |

  "metadata": {

<Note>
  Esse evento confirma apenas que a cobrança foi criada. Não libere o pedido antes de receber o evento `paid`.
</Note>

Responda com HTTP `2xx` depois de persistir o evento.
